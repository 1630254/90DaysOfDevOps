## 🔑 Recommended Branch Naming Pattern

- **`feat/`** → for new features  
  *Example: `feat/login-auth`*  

- **`fix/`** → for bug fixes  
  *Example: `fix/null-pointer-error`*  

- **`chore/`** → for maintenance tasks (dependencies, configs, cleanup)  
  *Example: `chore/update-dependencies`*  

- **`docs/`** → for documentation updates  
  *Example: `docs/readme-update`*  

- **`test/`** → for adding or modifying tests  
  *Example: `test/api-endpoints`*  

- **`refactor/`** → for restructuring code without changing functionality  
  *Example: `refactor/user-service`*
